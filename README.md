# Rental Payment Calculator

A mobile-friendly, one-click WhatsApp message generator for property agents.

## Usage

Open `index.html` in a browser, enter:

1. Property name / unit
2. Monthly rental
3. Payment structure: `2+1+0.5`, `1+1+0.5`, or `2+1+1`

The calculator generates the full payment breakdown and copies the formatted
message to the clipboard.

## Calculation

- Security deposit: 1 or 2 months, based on the selected structure
- Utilities deposit: 1/2 or 1 month, based on the selected structure
- Advance rental: 1 month
- Booking SST: 8% of advance rental
- Agreement and stamping: 1-year fee schedule effective May 2026

The supplied fee schedule supports monthly rentals up to RM18,000.
